# Evolution Placeholder Art — 2026-05-11

Purpose: quick placeholder visual language for the 5 starter egg evolution model.

Generated assets:

- `*_egg_placeholder.png` — Fire/Water/Earth/Light/Dark starter egg placeholders.
- `*_hatchling_placeholder.png` — cute starter dragon placeholders.
- `*_drake_placeholder.png` — first evolution scale placeholders.
- `*_young_placeholder.png` — young dragon placeholders.
- `*_dragon_placeholder.png` — city-raid scale placeholders.
- `*_ancient_placeholder.png` — ancient capstone placeholders.
- `evolution_placeholder_contact_sheet.png` — overview sheet for art direction review.

Design intent:

- Element color is readable at phone scale.
- Hatchlings remain cute; later stages add scale, horns, spikes, and aura markers.
- These are placeholders, not final art. Use them to validate UI layout, branch readability, and evolution-screen composition.
