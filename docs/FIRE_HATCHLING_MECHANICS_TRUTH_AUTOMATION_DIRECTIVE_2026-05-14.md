# Fire Hatchling — Mechanics Truth + Automation Directive

Source: `Fire_Hatchling_Mechanics_Truth_Automation_Directive.pdf` supplied by Topnotch on 2026-05-14.

## Current Phase

The Fire Hatchling is in **Mechanics Truth Phase**.

It is not in:

- final animation polish;
- ember beauty polish;
- presentation-only exports;
- cosmetic plume refinement;
- easing finesse passes.

## Meaningful Progress Gate

A production slice only counts as meaningful progress if it improves at least one of:

1. **Compression volume**
2. **Anatomical weighting**
3. **Jaw articulation**
4. **Recoil propagation**
5. **Internally driven creature mechanics**

## Energy Source Rule

The chest furnace/core is the root energy source.

All major attacks must visibly originate from:

1. chest compression;
2. heat buildup;
3. neck pressure;
4. jaw release;
5. recoil discharge.

The creature should feel:

- internally pressurized;
- furnace-driven;
- physically connected;
- reactive;
- weighted.
