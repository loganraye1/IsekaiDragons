# Isekai Dragons Agent Crew

These are role briefs for the Dragonforge agent company working on Isekai Dragons. They are intentionally lightweight project docs for now: Ember can use them to route work, and Mission Control can display them as the studio org chart.

For the full Dragonforge source-of-truth launchpad, start with `docs/DRAGONFORGE_OPERATING_INDEX.md`.

Current rule: the game is in a v0.1.0-alpha playtest-readiness phase. Do not add new mechanics or retune early balance until real iPhone/Expo Go playtesting produces repeated evidence that a change is needed.

## How Ember should use these briefs

1. Decide which agent perspective is most relevant to the work.
2. Read that role's brief before making recommendations or changes.
3. Keep decisions grounded in the current release notes, README, art bible, and actual app code.
4. Prefer small, reversible improvements until Logan approves larger direction changes.
5. Record meaningful decisions in project docs or OpenClaw memory so Mission Control stays useful.
6. Use `docs/CREW_OPERATING_SYSTEM.md` for authority, handoffs, and proof standards.
7. Use `docs/agents/WORKSPACE.md` for the current shared handoff chain.
