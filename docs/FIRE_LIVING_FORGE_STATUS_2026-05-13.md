# Fire Living Forge Status — 2026-05-13

## Current Status

The Fire evolution path has moved from generic fire-dragon placeholders into a clearer owned identity:

**Living Forge Dragon** — a mischievous ember hatchling that grows into a forge-hearted dragon, with the player build shown through flame, smoke, or magma branch silhouettes.

## What Is Working

- The identity phrase is strong and stakeholder-approved.
- The recurring motifs create a recognizable companion:
  - forge-heart chest glow
  - asymmetric obsidian/fire horn
  - smoke scarf/mane
  - cracked volcanic armor plates
  - coal-lantern / furnace tail
- The branch split has a readable gameplay/art mapping:
  - Flame / Raider = sharp, fast, explosive
  - Smoke / Mystic = evasive, magical, ash-cloaked
  - Magma / Guardian = armored, heavy, defensive

## Current Art Direction Concern

The branch concepts need to be pushed so they are identifiable by silhouette without labels. The next visual pass should exaggerate:

- Flame: leaner body, forward attack pose, blade-like fire fins.
- Smoke: ash cloak, softer hidden silhouette, rune/mote magic.
- Magma: chunkier body, shield-like head/shoulders, molten plate armor.

## Next Implementation Slice

1. Build a Fire evolution sheet in the project art board using the Living Forge motifs.
2. Replace or supplement generic Fire placeholder notes with branch-specific art requirements.
3. Use the Fire path as the standard template for Water, Earth, Light, and Dark later.
