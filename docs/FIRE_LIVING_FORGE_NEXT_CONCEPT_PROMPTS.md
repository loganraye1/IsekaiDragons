# Fire Living Forge — Next Concept Pass Prompts

Use these prompts for the next art iteration. Goal: move from generic fire dragon placeholders toward a recognizable Isekai Dragons Fire starter.

## Shared Visual Rules

- No baked-in text or labels.
- Cute-to-epic fantasy, mobile game readable.
- Keep the same companion identity across stages.
- Reuse these signature motifs: forge-heart chest glow, asymmetric obsidian/fire horn, smoke scarf/mane, cracked volcanic plates, coal-lantern tail.
- Silhouette should pass a 128px phone-size read.
