# Fire Hatchling — No-Overlay / 50% Readability Stress Test Directive

Source: Topnotch production directive on 2026-05-14.

## Phase

Production Mesh Truth Phase — readability validation slice.

Do not start a new mechanics phase. Do not add recoil logic, glow work, jaw opening, proxy overlays, or polish.

## Primary Goal

Validate the v10 production mesh chain without relying on debug rings or guide overlays, especially at 50% mobile scale.

This slice must prove whether the current production mesh weighting remains readable before final hand mesh-conversion / weight-painting in Spine Professional.

1. Jaw/cheek readability during compression and release.
2. Mouth-corner silhouette clarity.
3. Chest pressure read during brace/compression.
4. Neck arc clarity through recoil propagation.
5. Tail stabilization read without overlay assistance.
6. Seam stability and no floating/sliding vertices.
7. 50% scale readability of the full chain:
   - brace;
   - compression;
   - neck/jaw release;
   - recoil/tail stabilization.

## Scoring Target

Raise Jaw Articulation / readability from 5.8 by improving silhouette clarity only.

Do not interpret this as “open the jaw more.”

## Failure Guards

- no mush deformation;
- no over-softening;
- no silhouette collapse;
- no disconnected weighting islands;
- no unreadable compression;
- no new presentation-only fixes.

## Review Requirements

### No-Overlay Readability Review

Evaluate whether the action chain remains readable without debug rings, guide lines, pressure arrows, or explanatory overlays.

### 50% Mobile Readability Review

Evaluate whether chest pressure, mouth-corner/jaw release, neck arc, tail stabilization, and lantern lag remain visible at 50% scale.

### Silhouette Stability Review

Evaluate black-fill readability during brace, compression, release, recoil, and settle.

### Seam Stability Review

Evaluate whether lower neck, underlap, cheek/jaw bridge, tail root, and lantern connection avoid floating, sliding, mush, and disconnected islands.

### Correct Next-Slice Logic

If jaw articulation remains lowest, interpret it as **jaw/cheek silhouette readability under production mesh constraints**, not more mouth opening or hinge timing.
