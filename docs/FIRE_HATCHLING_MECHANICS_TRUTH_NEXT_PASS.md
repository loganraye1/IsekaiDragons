# Fire Hatchling — Mechanics Truth Next Pass

Source: Topnotch correction on 2026-05-14.

## Phase Name

The project is in **mechanics truth phase**, not final animation polish phase.

That distinction controls what work is valuable.

## Pipeline Focus

Only work that improves these four mechanics counts as progress:

1. **Compression volume**
   - chest/ribcage compresses before extension;
   - neck base pushes into body mass;
   - volume is preserved, not flattened by whole-layer squash;
   - compression is visible at combat/mobile scale.
2. **Anatomical weighting**
   - lower neck and collar vertices blend into torso influence;
   - underlap follows the torso/neck bridge, not an independent sticker pivot;
   - torso reacts to neck/head turns;
   - rigid plate rotation is eliminated.
3. **Jaw articulation**
   - jaw has separated art and hinge/controller support;
   - mouth opens after chest charge, not at frame zero;
   - jaw compresses/overshoots, then settles;
   - jaw motion supports breath/plume mechanics but is not decorative polish.
4. **Recoil propagation**
   - release travels jaw/head → neck root → torso → tail/lantern;
   - body receives recoil instead of head snapping alone;
   - tail/lantern settle on a delayed beat;
   - recoil remains readable without final VFX.

## Not This Phase

Do not prioritize:

- final plume beauty;
- ember polish;
- perfect easing curves;
- finished combat VFX;
- presentation-only contact sheets;
- broad mask expansion;
- static proof-health diagnostics.

These can happen later. During mechanics truth, they are only valid if they reveal or clarify the four mechanics above.

## Review Format For Next Update

Every update should answer:

- **Compression volume:** what now compresses, where is volume preserved, where does it still collapse?
- **Anatomical weighting:** which vertices/bones now share influence, where does sticker motion remain?
- **Jaw articulation:** what is separated/controlled, what still needs art separation?
- **Recoil propagation:** where does recoil start, where does it travel, where does it stop too early?

## Success Criteria For This Phase

The next pass succeeds only when the hatchling begins to feel like it has an internal spine/ribcage structure, even if the animation is still rough and unpolished.
