# Fire Hatchling — Facial Continuity + Anatomical Weighting Directive

Source: `Fire_Hatchling_Facial_Continuity_Weighting_Directive.pdf` supplied by Topnotch on 2026-05-14.

## Phase

Mechanics Truth Phase — not polish.

The accepted v3 jaw pass improved jaw articulation from **2.5 → 4.1**, but exposed a new structural weakness: the mouth-corner / cheek connection breaks facial continuity and can read as hollow missing geometry.

This is an anatomical overlap and weighting problem, not a cosmetic problem.

## Current Lowest Mechanics Category

**Anatomical Weighting — 3.2 / 10**

## Target Read

The target is:

> compressed furnace jaw

not:

> missing facial geometry

## Required Production Slice

1. Create mouth-corner anatomy bridge between:
   - upper skull;
   - cheek/jowl;
   - lower jaw.
2. Add overlapping cheek/jowl transition structure that:
   - partially covers jaw hinge;
   - preserves jaw articulation;
   - restores facial continuity;
   - prevents exposed hollow cavity look.
3. Weight overlap primarily to `head_root` / `head_neck`, with slight influence from `lower_jaw_hinge`.
4. Improve lower-neck / torso weighting:
   - add seam vertices;
   - improve chest/neck blend;
   - reduce sliding;
   - preserve compression volume.
5. Preserve visible jaw separation. Do not completely hide the hinge.
6. Maintain Energy Source Rule:
   - chest compression;
   - heat buildup;
   - neck pressure;
   - jaw release;
   - recoil discharge.

## Do Not Solve With

- more glow;
- smoothing;
- masking fixes;
- beauty polish;
- plume refinement;
- presentation cleanup.
