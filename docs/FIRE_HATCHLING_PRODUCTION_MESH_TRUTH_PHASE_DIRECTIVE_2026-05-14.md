# Fire Hatchling — Production Mesh Truth Phase Directive

Source: Topnotch director review acceptance on 2026-05-14.

## Phase

**Production Mesh Truth Phase** — production mesh weighting discipline.

The Integration Truth phase is accepted as a major milestone. The hatchling now reads more like one connected organism / shared pressure-recoil chain / internally driven creature system instead of isolated successful mechanics layered together.

## Objective

Convert the integrated mechanics system into production-quality weighted Spine mesh deformation while preserving silhouette clarity and force readability.

Highest-value goal:

> Preserve readability, silhouette clarity, and force perception while transitioning the hatchling from proof-driven mechanics into real production mesh deformation.

## This Is Not

- a new mechanics phase;
- new timing logic;
- more recoil design;
- more glow work;
- more overlay proxies;
- presentation polish.

## This Is

Production mesh weighting discipline.

## Primary Risk

Once full weighted meshes are introduced, the creature may deform “correctly” but lose:

- silhouette clarity;
- force readability;
- pressure readability;
- anatomical definition;
- visual stability.

## Required Production Slice

1. Convert integration-truth influence specs into real Spine Professional weighted mesh vertices:
   - body core;
   - chest/ribcage;
   - furnace core;
   - lower neck;
   - underlap;
   - cheek/jaw bridge;
   - tail root;
   - lantern connection.
2. Reduce dependency on overlay-only proof drivers where possible.
3. Preserve silhouette integrity during deformation:
   - neck arcs remain readable;
   - jaw silhouette remains clear;
   - chest compression remains identifiable;
   - tail stabilization remains readable;
   - pressure buildup remains visually understandable.
4. Prevent common production mesh failures:
   - mush deformation;
   - over-softening;
   - silhouette collapse;
   - floating vertices;
   - sliding seams;
   - disconnected weighting islands;
   - unreadable compression.
5. Preserve:
   - pressure-valve facial behavior;
   - recoil hierarchy;
   - source-pressure logic;
   - mass preservation;
   - unified organism chain.
