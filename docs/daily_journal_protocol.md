# Daily Dragonforge Journal Protocol

Purpose: create one readable daily record of what happened in Dragonforge without relying on Discord scrollback.

## Output Location

Daily journal files live in:

`docs/journal/YYYY-MM-DD.md`

These are narrative summaries. Raw memory notes still live in `memory/YYYY-MM-DD.md`.

## Daily Entry Shape

Each entry should include:

- Date and phase.
- Completed work with evidence.
- Current in-progress work and owner.
- Blockers or risks.
- Logan / Topnotch tasks.
- Crew snapshot.
- Decisions or corrections worth remembering.
- Suggested next move.

## Rules

- Do not invent progress.
- Prefer proof-backed notes from docs, memory, work logs, git state, or scheduled updates.
- Keep it Discord-readable and useful for the next morning.
- If nothing changed, write that plainly.
- If a durable decision appears, also add it to `memory/YYYY-MM-DD.md` and graduate to `MEMORY.md` when it should guide future sessions.
